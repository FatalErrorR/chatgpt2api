chatgpt2api 界面重设计

设计稿 v1 · 参考 Anthropic 官网与 Claude 的视觉语言：暖象牙底色、暖调近黑文字、陶土橙作为唯一强调色、衬线标题配无衬线正文、细线代替阴影、留白充足、语气平静。确认方向后再逐页落到代码。

设计原则

现在的界面信息多、颜色杂（状态用大色块、按钮颜色各异、阴影和渐变混用）。重做的核心是让「数据」成为主角，界面本身退到背后。

  • 一个强调色：陶土橙只给「主要操作」和「当前位置」，同一屏最多出现一两处
  • 状态用「圆点 + 文字」，不用填满的彩色块；颜色只表达含义，不做装饰
  • 标题用衬线字体，数字、表格、按钮用无衬线，代码和 token 用等宽
  • 用 1px 细线分隔区域，几乎不用阴影；只有浮层（对话框、输入框）有一层很浅的投影
  • 低频操作收进「…」菜单或选中后才出现的操作条，常驻按钮控制在 3 个以内
  • 中文界面统一用简体、句子式文案，不用感叹号和 emoji（如现在的 🧹、🗜️）
  • 导航改为左侧 64px 窄图标栏（图标 + 小字），与 Claude 收起侧栏时一致，宽度全部留给内容
  • 深色模式用暖调深灰（不是纯黑），与浅色共用同一套语义变量

落地顺序

确认设计后分四批改，每批单独部署，避免一次改动过大。

  • 第 1 批：主题变量、字体、基础组件（按钮、输入、状态、对话框）、左侧导航框架、登录页
  • 第 2 批：号池页与代理对话框（最常用）
  • 第 3 批：生图页（会话栏、结果流、输入框）
  • 第 4 批：图片管理、日志、设置、调试页，以及深色模式全面检查
